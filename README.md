# FFXIV 宇宙探索（月球）規劃站

繁中服「宇宙探索」的離線規劃工具。線上版：https://cosmic.xivtc.com/

- **緊急事件** — 七台伺服器的即時現況、通報與附議、任務地點圖、Discord 訂閱通知。**這一頁是唯一有後端的**（見下）。
- **臨時任務** — 現在有哪些任務條件成立、下一批是什麼時候，可設條件開啟前的鬧鐘。
- **天氣預報** — 渴望灣的月塵／晴朗／靈風時間軸，可推算到任意未來。天氣是時間的純函數，全 7 個繁中服伺服器同步，不必選伺服器。
- **任務清單** — 544 個任務的職業／難度／時限／開放條件／需求物／信用點獎勵，可依「現在符合條件」篩選；製作類的需求物可一鍵跳到製作求解器。

## 算得準的 vs 只能靠回報

**天氣與 ET 時段是時間的純函數** ⇒ 算得到任意未來，不必選伺服器。

**緊急事件（磁暴／流星雨／孢子霧）算不出來**：那三種天氣**不在遊戲的任何天氣機率表內**，
時間演算法永遠擲不出來，只能由伺服器推播。所以 2026-08-02 起改由**回報**——Dalamud 插件自動偵測
加上玩家手動通報，後端是一支 Cloudflare Worker（`worker/`）。
**天花板寫在畫面上：覆蓋率＝回報者人數，沒亮不代表沒事件。**

> ⚠️ 本段原本寫「並標出緊急任務的**必要條件視窗**（靈風時段）」——**該說法已於 2026-08-02 證偽**：
> 掛靈風條件的 20 個任務全部是臨時任務，33 個緊急任務的條件欄**全部是空的**，client 裡沒有任何
> 欄位把緊急任務綁到任何天氣。站上的文案當時就改了，這份 README 沒跟著改（2026-08-08 健檢抓到）。

## 資料來源

網站本身零外部依賴。台服改版後重跑：

```bash
dotnet run -c Release --project tools/cosmic-dump
```
