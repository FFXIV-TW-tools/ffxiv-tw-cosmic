# FFXIV 宇宙探索（月球）規劃站

繁中服「宇宙探索」的離線規劃工具。線上版：https://cosmic.xivtc.com/

- **天氣時間軸** — 渴望灣的月塵／晴朗／靈風，可推算到任意未來。天氣是時間的純函數，全 7 個繁中服伺服器同步，不必選伺服器。
- **任務清單** — 544 個任務的職業／難度／時限／開放條件／需求物／信用點獎勵，可依「現在符合條件」篩選。
- **宇宙工具** — 11 職各 9 階的升級鏈（原型 v0.1 → v0.8 → 成品）。

## 不提供什麼

緊急事件（磁暴／流星雨／孢子霧）**不在遊戲的天氣機率表內**，只能由伺服器推播，離線推算不出來；
且每個伺服器、每個實例各自計時。本站因此只做算得準的部分，並標出緊急任務的**必要條件視窗**（靈風時段）。

## 資料來源

`data/*.json` 由 `tools/cosmic-dump` 從台服 client 的 sqpack 解出（需要本機有遊戲），已 commit 進 repo，
網站本身零外部依賴。台服改版後重跑：

```bash
dotnet run -c Release --project tools/cosmic-dump
```

規則與驗證見 [`AGENTS.md`](AGENTS.md)。
